What's new

Steam Library

Leave the root blank and KOVA auto-detects your Steam install.

Standalone Game Folders

Folders KOVA scans for games that didn't come from a store — .app bundles, .exe files, AppImages, Linux binaries. When this list is empty, KOVA checks ~/Games and ~/KOVA Games instead.

Library Visibility

Games you hide (from their game page) disappear from Home, the Library, and the Quick Panel. Hiding is always reversible — hidden games are listed here with an Unhide button.

Collections

Shelves beyond Favorites: Playing now, Backlog, Finished, plus your own. A game can sit on more than one shelf — assign games from their game page.

Kids shelf

When the Kids shelf is on, the Library shows only the games you approve, and launching anything else is blocked. The daily limit counts playtime from games launched in KOVA.

Cloud sync

Sync your profile and state through your own cloud folder — iCloud Drive, Google Drive, or any folder that syncs. KOVA has no server holding your data. Push sends this machine's state to the folder; Pull replaces this machine's state with the folder's copy (last-write-wins).

State backup

Your gamertag, profiles, wishlist, and shelves live in one file on this machine. Export a copy for safekeeping; import replaces everything with the file's contents.

Disk space

How much room each game takes. Sizes are measured from the install folders KOVA knows — Steam and web titles report no size, and some folders are only partly counted.

KOVA Beta Program

Join the beta to try the upcoming platform UI early — a brand-new light shell you can switch to from here. The current UI stays the main UI; the beta is an option, not a replacement.

Quick Panel

Press ⌘+Shift+K anywhere to summon the KOVA Quick Panel — your library and Quick Resume, floating over the desktop. Esc closes it.

Your recents are also in the menu bar — KOVA's tray icon launches your recent games without opening the window.
